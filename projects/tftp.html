📡 TFTP Implementation

A from-scratch implementation of the Trivial File Transfer Protocol (TFTP) in C using UDP sockets — featuring a multi-mode server, a command-driven client, block-by-block ACK handshaking, NetASCII/Octet transfer modes, and reliable file transfer over an unreliable network layer.

Project Overview

TFTP (RFC 1350) is a simple file transfer protocol that runs over UDP. Unlike FTP, it has no authentication, no directory listing — just read and write requests. This project implements both the server and client sides in C using raw UDP socket programming.

The server listens on port 6969, receives RRQ (Read Request) and WRQ (Write Request) packets, and calls send_file() or receive_file() accordingly. The client connects to a server IP, and supports get and put commands with configurable transfer modes. Every 512-byte data block requires an ACK before the next is sent — implementing the stop-and-wait protocol.

Protocol Flow

TFTP uses a strict stop-and-wait mechanism — each data block must be acknowledged before the next is sent.

Read Request (RRQ)

Client → Server : RRQ (filename, mode)
Server → Client : DATA block #1 (≤512 bytes)
Client → Server : ACK block #1
Server → Client : DATA block #2
Client → Server : ACK block #2
... repeat ...
Server → Client : DATA block #N (0 bytes = EOF)
Client → Server : ACK block #N

Write Request (WRQ)

Client → Server : WRQ (filename, mode)
Server → Client : ACK block #0 (ready)
Client → Server : DATA block #1
Server → Client : ACK block #1
Client → Server : DATA block #2
Server → Client : ACK block #2
... repeat ...
Client → Server : DATA block #N (0 bytes = EOF)
Server → Client : ACK block #N

TFTP OpCode Reference

OpCodeNameDirectionDescription
1 — RRQRead RequestClient → ServerRequest to download a file from the server
2 — WRQWrite RequestClient → ServerRequest to upload a file to the server
3 — DATAData PacketBoth512-byte (max) block of file data with block number
4 — ACKAcknowledgmentBothConfirms receipt of a specific block number
5 — ERRORError PacketBothError code and message for transfer failures

Core Features

UDP Socket Server

Server binds to port 6969, listens for incoming packets in a loop, and dispatches RRQ/WRQ to the appropriate handler.

Command-Driven Client

Client supports connect, get, put, mode, and disconnect commands interactively.

Block ACK Handshaking

Every 512-byte data block must be acknowledged before the next is sent. Mismatched ACK block numbers trigger automatic retransmission.

Transfer Modes

Supports Octet (binary, byte-by-byte) and NetASCII (text, with CR/LF conversion) transfer modes.

NetASCII Conversion

On send, \n is prefixed with \r. On receive, \r characters are stripped — compliant with RFC 1350.

Timeout Handling

Socket timeout configured via setsockopt(SO_RCVTIMEO) to handle unresponsive peers and avoid infinite blocking.

    WRQ   = 2,  // Write Request
    DATA  = 3,  // Data Packet
    ACK   = 4,  // Acknowledgment
    ERROR = 5   // Error Packet
} tftp_opcode;

/* Unified TFTP packet structure */
typedef struct {
    uint16_t opcode;
    union {
        struct {
            char filename[256];
            char mode[16];       // "octet" or "netascii"
        } request;               // RRQ and WRQ
        struct {
            uint16_t block_number;
            char     data[512];
        } data_packet;           // DATA
        struct {
            uint16_t block_number;
        } ack_packet;            // ACK
        struct {
            uint16_t error_code;
            char     error_msg[512];
        } error_packet;          // ERROR
    } body;
} tftp_packet;

/* ── Send a file to the client block by block ───────────────────────────── */
void send_file(int sockfd, struct sockaddr_in client_addr,
               socklen_t client_len, char *filename, int mode)
{
    if (access(filename, F_OK | R_OK) != 0) {
        printf("File %s is not readable\n", filename);
        return;
    }
    FILE *fp = fopen(filename, "rb");
    if (!fp) { printf("Couldn't read file\n"); return; }

    /* Octet = 1 byte/read (binary), NetASCII = 512 bytes/read (text) */
    int chunk_size = (mode == MODE_OCTET) ? 1 : 512;

    char   buffer[512];
    int    bytes, block_number = 1;

    while ((bytes = fread(buffer, 1, chunk_size, fp)) > 0) {

        tftp_packet send_data;
        memset(&send_data, 0, sizeof(send_data));
        send_data.opcode                        = htons(DATA);
        send_data.body.data_packet.block_number = htons(block_number);

        int packet_size;

        if (mode == MODE_NETASCII) {
            /* Insert \r before every \n for NetASCII compliance */
            char new_buffer[1024];
            int  new_len = 0;
            for (int i = 0; i < bytes; i++) {
                if (buffer[i] == '\n') new_buffer[new_len++] = '\r';
                new_buffer[new_len++] = buffer[i];
            }
            memcpy(send_data.body.data_packet.data, new_buffer, new_len);
            packet_size = new_len + 4;
        } else {
            memcpy(send_data.body.data_packet.data, buffer, bytes);
            packet_size = bytes + 4;
        }

        sendto(sockfd, &send_data, packet_size, 0,
               (struct sockaddr *)&client_addr, client_len);

        /* Wait for ACK */
        tftp_packet response;
        int recv_len = recvfrom(sockfd, &response, sizeof(response), 0,
                                  (struct sockaddr *)&client_addr, &client_len);
        if (recv_len < 0) { printf("ACK not received\n"); fclose(fp); return; }
        if (ntohs(response.opcode) != ACK) { printf("Expected ACK\n"); fclose(fp); return; }

        uint16_t ack_block = ntohs(response.body.ack_packet.block_number);
        if (ack_block != block_number) {
            /* Wrong ACK — retransmit same block */
            sendto(sockfd, &send_data, packet_size, 0,
                   (struct sockaddr *)&client_addr, client_len);
            continue;
        }
        if (bytes < chunk_size) break;
        block_number++;
    }

    /* Send zero-length DATA packet to signal EOF */
    int eof_block = (mode == MODE_OCTET) ? block_number : block_number + 1;
    tftp_packet final_packet;
    memset(&final_packet, 0, sizeof(final_packet));
    final_packet.opcode                        = htons(DATA);
    final_packet.body.data_packet.block_number = htons(eof_block);
    sendto(sockfd, &final_packet, 4, 0,
           (struct sockaddr *)&client_addr, client_len);

    tftp_packet eof_ack;
    recvfrom(sockfd, &eof_ack, sizeof(eof_ack), 0,
             (struct sockaddr *)&client_addr, &client_len);

    fclose(fp);
}

/* ── Receive a file from the client block by block ──────────────────────── */
int receive_file(int sockfd, struct sockaddr_in client_addr,
                 socklen_t client_len, char *filename, int mode)
{
    FILE *fp = fopen(filename, "wb");
    if (!fp) { printf("Couldn't open file for writing\n"); return -1; }

    tftp_packet ack;
    memset(&ack, 0, sizeof(ack));
    ack.opcode = htons(ACK);

    int chunk_size    = (mode == MODE_OCTET) ? 1 : 512;
    int block_number  = 1;

    while (1) {
        tftp_packet receive_data;
        int bytes = recvfrom(sockfd, &receive_data, sizeof(receive_data), 0,
                              (struct sockaddr *)&client_addr, &client_len);
        if (bytes < 0) { printf("Timeout or receive error\n"); fclose(fp); return -1; }

        if (ntohs(receive_data.opcode) != DATA) {
            printf("Expected DATA packet\n"); fclose(fp); return -1;
        }

        int      data_len       = bytes - 4;
        int      received_block = ntohs(receive_data.body.data_packet.block_number);

        if (received_block != block_number) {
            /* Out-of-order block — re-ACK last good block */
            ack.body.ack_packet.block_number = htons(block_number - 1);
            sendto(sockfd, &ack, 4, 0, (struct sockaddr *)&client_addr, client_len);
            continue;
        }
        if (data_len == 0) {
            /* EOF — acknowledge and exit loop */
            ack.body.ack_packet.block_number = htons(block_number);
            sendto(sockfd, &ack, 4, 0, (struct sockaddr *)&client_addr, client_len);
            break;
        }

        if (mode == MODE_NETASCII) {
            /* Strip \r characters (reverse of send conversion) */
            char new_buffer[1024];
            int  new_len = 0;
            for (int i = 0; i < data_len; i++)
                if (receive_data.body.data_packet.data[i] != '\r')
                    new_buffer[new_len++] = receive_data.body.data_packet.data[i];
            fwrite(new_buffer, 1, new_len, fp);
        } else {
            fwrite(receive_data.body.data_packet.data, 1, data_len, fp);
        }

        ack.body.ack_packet.block_number = htons(block_number);
        sendto(sockfd, &ack, 4, 0, (struct sockaddr *)&client_addr, client_len);
        block_number++;
    }
    fclose(fp);
    return 0;
}

int main() {
    int sockfd;
    struct sockaddr_in server_addr, client_addr;
    socklen_t    client_len = sizeof(client_addr);
    tftp_packet packet;

    /* Create UDP socket */
    sockfd = socket(AF_INET, SOCK_DGRAM, 0);
    if (sockfd == -1) { printf("Couldn't create socket\n"); return 0; }

    /* Configure socket timeout */
    struct timeval tv = { .tv_sec = TIMEOUT_SEC, .tv_usec = 0 };
    // setsockopt(sockfd, SOL_SOCKET, SO_RCVTIMEO, &tv, sizeof(tv));

    /* Bind to all interfaces on PORT */
    server_addr.sin_family      = AF_INET;
    server_addr.sin_port        = htons(PORT);
    server_addr.sin_addr.s_addr = INADDR_ANY;

    if (bind(sockfd, (struct sockaddr *)&server_addr, sizeof(server_addr)) < 0) {
        perror("bind"); close(sockfd); return 1;
    }

    printf("TFTP Server listening on port %d...\n", PORT);

    /* Main request loop */
    while (1) {
        int n = recvfrom(sockfd, &packet, BUFFER_SIZE, 0,
                         (struct sockaddr *)&client_addr, &client_len);
        if (n < 0) { perror("Receive failed or timeout"); continue; }
        handle_client(sockfd, client_addr, client_len, &packet);
    }

    close(sockfd);
    return 0;
}

void handle_client(int sockfd, struct sockaddr_in client_addr,
                   socklen_t client_len, tftp_packet *packet)
{
    char *filename = packet->body.request.filename;
    int   mode;

    /* Parse transfer mode string */
    if      (!strcmp(packet->body.request.mode, "octet"))    mode = MODE_OCTET;
    else if (!strcmp(packet->body.request.mode, "netascii")) mode = MODE_NETASCII;
    else                                                        mode = MODE_DEFAULT;

    if (ntohs(packet->opcode) == RRQ) {
        printf("RRQ: %s (mode: %s)\n", filename, packet->body.request.mode);
        send_file(sockfd, client_addr, client_len, filename, mode);
        printf("File '%s' sent successfully.\n", filename);

    } else if (ntohs(packet->opcode) == WRQ) {
        printf("WRQ: %s (mode: %s)\n", filename, packet->body.request.mode);
        /* ACK block 0 to signal server is ready to receive */
        tftp_packet ack0;
        memset(&ack0, 0, sizeof(ack0));
        ack0.opcode                      = htons(ACK);
        ack0.body.ack_packet.block_number = htons(0);
        sendto(sockfd, &ack0, 4, 0,
               (struct sockaddr *)&client_addr, client_len);
        receive_file(sockfd, client_addr, client_len, filename, mode);
        printf("File '%s' received successfully.\n", filename);
    }
}

Key Challenges & Solutions

Retransmission Logic

When an ACK with the wrong block number is received, the same data packet is resent rather than advancing — ensuring no block is skipped on a lossy link.

NetASCII Conversion

Text files require inserting \r before \n on send and stripping \r on receive — handled transparently based on the negotiated mode.

EOF Signalling

A final DATA packet with zero bytes signals end-of-file. Octet and NetASCII modes calculate the EOF block number differently due to chunk size differences.
